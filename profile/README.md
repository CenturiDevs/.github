## Hi there 👋

**Centuri** is an open-source, next-generation streaming ecosystem built for ultra-low latency, full data ownership, and highly customizable live broadcasts.

### 🙋‍♀️ What is Centuri all about?
We build high-performance streaming infrastructure that keeps live video open and lightning-fast. Centuri gives creators and developers the tools to stream without proprietary limits or high costs.

### 🌈 Contribution guidelines
We thrive on community support! You can get involved by:
* **Code:** Fixing bugs or building features marked `good-first-issue`.
* **Docs:** Improving our guides or translation files.
* **Feedback:** Opening issues to suggest new streaming tools.

Please read our `CONTRIBUTING.md` before submitting a pull request.

### 👩‍💻 Useful resources
* **Documentation:** Core deployment steps and API references at `docs.centuri.stream`.
* **Quickstart Guide:** Docker and Kubernetes snippets in our `getting-started` repo.
* **Community:** Connect with fellow developers on our official Discord server.

### 🍿 Fun facts
* **Fuel:** Powered entirely by cold brew coffee and spicy ramen.
* **The Name:** Inspired by Alpha Centauri, because your data should move at the speed of light.
* **Alpha Test:** Our first successful live stream was a 24-hour loop of a rubber duck in a sink.
